# Code of Conduct

hece follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and focus on what's best for the community. Harassment and personal attacks aren't tolerated.

To report unacceptable behavior, contact the maintainer, [@harungokcegoz](https://github.com/harungokcegoz), using the email address on their GitHub profile. Reports are handled privately.
